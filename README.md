# حاسبة التركس والكومبلكس السورية (Syrian Trix & Complex Calculator)

تطبيق أندرويد متكامل ومتقدم مبني باستخدام **Kotlin** و **Jetpack Compose (Material Design 3)** لحساب وتدوين نتائج لعبة الورق الشهيرة **التركس (Trix)** و **الكومبلكس (Complex)** وفق أدق القواعد السورية الأصيلة.

---

## 🌟 الميزات الرئيسية والتصميم

1. **واجهة عربية كاملة 100% مع دعم أصيل لليمين إلى اليسار (RTL Support)**:
   - تم بناء الواجهة بالكامل داخل حاوية `CompositionLocalProvider(LocalLayoutDirection provides LayoutDirection.Rtl)` لضمان انسيابية الخطوط والقوائم والجداول.
2. **الوضع الليلي الفاخر (Dark Mode Table Styling)**:
   - تصميم افتراضي داكن مريح للعين في جلسات اللعب الطويلة، مع لمسات ذهبية ملكية (`GoldPrimary`) وخضراء كازينو (`EmeraldAccent`) تماثل طاولات الورق الفاخرة، مع تقليل استهلاك البطارية.
3. **تهيئة مرنة للعبة (Configuration Screen)**:
   - **نظام اللعب (Game Mode)**: فردي (يهودي) أو شراكة (Partners).
   - **نوع اللعبة (Game Type)**: عادي (5 طلبات لكل مملكة) أو كومبلكس (شوطان: كومبلكس وتركس).
   - **التدبيل (Doubling)**: خيار تفعيل أو إلغاء مضاعفة ختيار الكبة والبنات.
   - **طريقة تسجيل الشراكة (Partner Scoring Rule)**: تظهر شرطياً بحركة سلسة (Animated Reveal) عند اختيار "شراكة":
     - *تسجيل لفريقين*: عرض مجموع نقاط الفريقين جنباً إلى جنب.
     - *تسجيل على فريق واحد*: حساب الفارق المباشر بين الفريقين (طريقة المقاهي الشعبية).
4. **محرك حساب دقيق لقواعد التركس السورية (Syrian Scoring Engine)**:
   - **ختيار الكبة (الشيخ)**: -75 نقطة.
   - **البنات**: -25 نقطة لكل بنت (المجموع -100).
   - **الديناري**: -10 نقاط لكل كرت (13 كرت = -130 نقطة).
   - **اللطوش (اللطو)**: -15 نقطة لكل أكلة (13 أكلة = -195 نقطة).
   - **التركس**: الأول +200، الثاني +150، الثالث +100، الرابع +50 (المجموع +500 نقطة).
   - **قاعدة الصفر (Zero-Sum)**: مجموع كل مملكة = صفراً (-500 سلبيات + 500 تركس).
5. **قواعد التدبيل السورية الأصيلة**:
   - الختيار المدبل: الآكل ينزل عليه **-150** نقطة، والمدبل يحصل على **+75** نقطة مكافأة. (إذا أكل المدبل ختياره بنفسه ينزل عليه -150).
   - البنات المدبلة: البنت المدبلة تخصم **-50** نقطة على الآكل، ويحصل مدبلها على **+25** نقطة.
6. **نظام الكومبلكس (Complex Mode)**:
   - يدمج الختيار، البنات الأربعة، الـ 13 ديناري، والـ 13 لطوش في شوط واحد بمجموع سالب -500 نقطة.
   - تنتهي اللعبة بـ 8 جولات سريعة (شوطان لكل لاعب).
7. **إدارة الحالة المتينة (Robust State Management & ViewModel)**:
   - تراجع فوري عن أي جولة سابقة (**Undo**).
   - إمكانية تعديل أي جولة قديمة من **سجل الجولات (Round History)** دون فقدان تقدم اللعبة، مع إعادة حساب النقاط التراكمية والفوارق تلقائياً.
   - فحص وتدقيق صارم لصحة المدخلات (مجموع الكروت والأكلات 13 و4) مع رسائل تنبيه عربية توضيحية فورية.

## 🚀 كيفية تشغيل المشروع في Android Studio

1. **فتح المشروع**:
   - شغّل برنامج **Android Studio** (نسخة Hedgehog أو Jellyfish أو أحدث).
   - اختر **File -> Open** وحدد مسار مجلد المشروع:
     `/home/murhaf/Documents/projects/Full-Stack/TrixCalculator`
2. **مزامنة الـ Gradle (Sync Project with Gradle Files)**:
   - سيقوم أندرويد ستوديو تلقائياً بمزامنة ملفات الـ Gradle وتحميل حزم Jetpack Compose و Material 3.
   - يتطلب المشروع **JDK 17** أو **JDK 21** (المضبوط افتراضياً في إعدادات Gradle).
3. **تشغيل الاختبارات (Run Unit Tests)**:
   - انقر بالزر الأيمن على ملف `ScoringEngineTest.kt` واختر **Run 'ScoringEngineTest'**.
   - ستجتاز كافة الاختبارات للتأكد من مطابقة جميع عمليات الحساب السورية والتدبيل.
4. **التشغيل على المحاكي أو جهاز حقيقي**:
   - اختر جهاز المحاكي (Emulator) أو هاتفك الأندرويد المتصل عبر USB.
   - اضغط على زر **Run 'app'** (أو `Shift + F10`).
